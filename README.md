# HackROX

An interactive cybersecurity-learning terminal project concept.

## Project scope

The portfolio describes a browser-based terminal experience with a curated library of information-security and Linux commands.

## Technologies listed in the portfolio

- Vanilla JavaScript
- Interactive terminal interface
- Curated cybersecurity command reference

## Status

This repository currently contains project documentation only. Source code, command-reference contents, and security-review evidence are not included. Commands should only be used in authorized environments.
